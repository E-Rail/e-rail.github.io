Docs / Privacy

Local by default.
Online when named.

Just-Go has no account, ad network, analytics SDK, or Just-Go data server. This policy explains the smaller set of actions that contact Apple, a transit operator, DATA.GOV.HK, GitHub Pages, or a link you choose to open.

01 / SUMMARY

Just-Go does not run a user-data backend.

Routing data ships with the app

Bundled metro networks and station packs are read locally.

Quick Tags stay local

Home, Work, and custom place tags are stored on the device.

Operator content is requested directly

Where supported, the rider’s device contacts the named operator—not a Just-Go proxy.

Saved responses are clearable

Device-only operator snapshots and downloaded packs can be removed in Settings.

There is no camera feature

Round 36 ships no personal station-photo feature or station-sign scanner.

02 / ON YOUR DEVICE

Your private layer remains private.

03 / NETWORK REQUESTS

Online features identify their provider.

Just-Go does not combine these provider requests into a Just-Go profile.

04 / CACHE AND DELETION

Clear Cache removes the cached layers.

After confirmation, Settings → Clear Cache deletes downloaded city packs, in-memory pack copies, in-flight downloads, stored station-information snapshots, and URL caches.

What Clear Cache keeps

Your Quick Tags, trips, records, preferences, and settings are not deleted by this action. Bundled cities continue to work from the app bundle.

Deleting the app removes its local container under the normal iOS deletion behavior. Device backups and operating-system services remain governed by Apple.

05 / EXTERNAL LINKS

A reviewed link is still external.

Just-Go stores reviewed URL metadata for transit resources. It does not make a destination page, PDF, image, or map part of the app merely by linking to it. Opening a destination is a rider action and places that request under the destination provider’s privacy policy.

06 / THIS WEBSITE

A static site with one preference.

  • Language preferenceThe site may store the selected language locally and in a short-lived cookie so navigation remains consistent.
  • System fontsThe site does not contact a third-party font service.
  • Hosting metadataGitHub Pages and ordinary network infrastructure may receive standard request metadata such as IP address, browser headers, requested path, and time.
  • No website accountThe site has no sign-in, form submission, analytics SDK, advertising tracker, or payment system.

07 / CHANGES

The policy changes when the product changes.

If Just-Go adds account sync, uploads, analytics, advertising, a community backend, another live provider, or a materially different use of local records, this policy will be revised and the effective date will change.
