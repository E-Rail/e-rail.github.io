01 / VERIFIED SNAPSHOT

The totals reconcile.

Round 36 catalogs 58 cities: 53 have route-picker baselines and 5 are catalog-only. Fourteen baseline cities also have included offline station packs.

58 cataloged cities = 53 with route-picker baselines + 5 catalog-only 53 route-picker cities = 14 with included offline city packs + 39 geometry-only, source-pending 14 included offline city packs = 2,849 matched station records of 4,177 network stations 44 source-pending cities = 39 geometry-only + 5 catalog-only 1,598 reviewed station-information entries = 1,436 fetched on-device (Beijing 416, Shanghai 415, Guangzhou 346, Hangzhou 259) + 162 from the Hong Kong pack
What “source-pending” means

The project has not included a supported station-enrichment pack for that city. It does not mean the city or its operator has no public information; it means that information is not included in this build as a supported Just-Go dataset.

02 / COUNTING RULES

Four labels prevent double-counting.

LabelExact meaningCounts as offline app content?Can trigger a network request?
IncludedData or media delivered as part of the app build.YESNot merely to read the included item.
Station-information referenceA reviewed operator station identifier. Only the identifier, aliases, and review date are in the repository; the content is not.THE REFERENCE ONLYYes, when the rider opens that station’s detail page.
Official-resource hyperlinkReviewed URL metadata for a provider-controlled page or file. The destination content is not included.NOOnly after the rider taps the link.
Live API referenceA station or line reference that can request a current value from an online provider.THE REFERENCE ONLYYes, when current results are requested.

A hyperlink record can ship in the directory without making its destination an included asset. Likewise, a live-arrival reference can be included while the current arrival result remains online-only, and a station-information reference can be included while the operator’s text is never committed to the repository.

Device-only caching is not redistribution

Beijing, Shanghai, Guangzhou, and Hangzhou station content is licensed for external linking only, so it must not be committed. The rider’s own device fetches it and stores the last good snapshot under a backup-excluded cache directory, capped at 1 MB per entry and clearable from Settings. That copy never leaves the device and is never republished as a Just-Go dataset.

03 / OFFICIAL-RESOURCE DIRECTORY

770 records, 698 unique targets.

The directory is separate from the 14 offline city packs. It stores reviewed factual URL metadata; it does not add station data or offline map coverage to a city. Forty-three cities have at least one verified official resource, and 15 carry an explicit dated no-resource review.

URL metadata is not operator content

Operator pages and files open only after the rider taps a link. Just-Go does not bundle, fetch, preview, cache, prefetch, or redistribute them.

05 / STATION INFORMATION

1,598 stations, fetched not bundled.

Station Detail shows exactly three categories. Four mainland operators are read live from the rider’s device because their content is licensed for external linking only; Hong Kong is served from its included pack.

Only station identifiers, operator keys, aliases, and verification dates live in the repository. Responses use an ephemeral session with a 1 MB cap, are validated against the requested station identity, and are stored as a device-only snapshot. A snapshot is served—clearly labeled as saved and dated—only when the operator is unreachable; a contract or identity violation never falls back to it.

Production still requires operator review

These endpoints are not published public APIs and no compatible content-reuse license was found. The current posture is fetch-on-device and redistribute-to-nobody; shipping to a store still requires operator or legal review.

08 / EXTERNAL & LIVE BEHAVIOR

User action and network behavior are explicit.

01Included station view

Read the included city-pack record locally. No operator webpage is contacted merely because a reference exists.

02Station Detail opens

For a station backed by a live-fetch source, request the operator’s own page for that station identifier, validate the returned identity, and render selected text as native rows. Store the result device-only.

03Official-resource link

Open the provider destination only after the rider taps it. Just-Go does not bundle, prefetch, or redistribute the page or file.

04Live arrivals

When the rider requests current Hong Kong arrivals, contact the DATA.GOV.HK government transport API using the referenced station and line context.

09 / UNIVERSAL CITY DATA

All 58 cities in one published format.

The Universal City Data Format republishes each catalog city as a single versioned JSON document—network graph without path geometry, reviewed station details, official resources, coverage, and rights declarations—alongside an integrity index carrying a sha256 and byte size per file.

These files are published for developers and are not bundled into the app. Each declares the full union of its source rights, so an ODbL or DATA.GOV.HK obligation travels with the data rather than being stripped by the reformatting. The generator is deterministic and CI runs it twice and diffs the output.

10 / MAINTENANCE RULES

Future updates must preserve the distinctions.

  • Increase an included count only when the corresponding data ships as part of the app content.
  • Count directory records separately from unique targets and from included files.
  • Count an operator map as external unless a licensed map file itself is included.
  • Count a live reference separately from a static schedule and from a live response.
  • Count a fetched-and-cached station snapshot as operator content on the rider’s device, never as an included dataset or a redistributable file.
  • Do not count a transfer as verified without a source-backed indoor path that establishes the transfer.
  • Update the privacy, terms, attribution, services, download, product, and documentation pages together when a data boundary changes.
