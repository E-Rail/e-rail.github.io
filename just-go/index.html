The rule

Missing data should look missing — not plausible.

Just-Go combines bundled network graphs, Apple Maps place search and walking legs, reviewed station packs, and narrowly scoped operator requests. Every layer keeps its own label, so a link never masquerades as offline content and a cached result never masquerades as live.

Bundled
53 city graphs and track geometry. Ships with the app. No request is needed to read the network.
Station pack
14 cities, 2,849 matched records. Only fields that exist are claimed. Coverage is counted field by field.
Operator · live
Five reviewed sources, 1,598 station references. Fetched by your device when you ask. Just-Go re-hosts nothing.
On this device
Backup-excluded, clearable in Settings. A saved answer shows its age and never poses as live.
No source
Left empty on purpose. No invented indoor paths, no guessed transfers, no filler.

Round 36 · six changes

Built for the
journey itself.

PR #21 makes the everyday experience faster, more personal, and clearer about data.

RoutingMap-first routing
Plan across 53 metro networks, start from any searched place, and see walking, cycling, driving, and rail legs as distinct parts of one journey.
Quick TagsUnlimited Quick Tags
Keep one Home and one Work, then add as many custom tags as you need — for stations or arbitrary map places — and manage them from Settings.
OfflineOfficial data, cached locally
Beijing’s last good operator response can work offline from a backup-excluded device cache, visibly labeled with its saved time.
CacheClear Cache means clear
One confirmed action removes downloaded city packs, station-information snapshots, URL caches, memory copies, and in-flight downloads — without deleting tags, trips, or settings.
APIOne station-information contract
A developer-facing schema, directory, and source registry describe 1,598 stations across five official sources. It is a contract, not a hosted proxy.
DataUniversal city data
Every catalog city now has a versioned, integrity-indexed JSON document for developers, while the app bundles only the data it actually uses.
